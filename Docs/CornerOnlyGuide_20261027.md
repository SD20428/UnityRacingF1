# 코너 전용 주행 가이드

적용: Apex Park, Harbor Run, Yas Marina의 일반 레이스 경로와 예선 레이싱 라인.

## 동작

- 긴 직선에서는 목표 속도 문구와 해당 직선의 가이드 화살표를 표시하지 않는다.
- 코너에서는 표시하며, 코너 전 직선도 현재 속도에 맞는 제동 거리 안으로 들어오면 제동 안내를 표시한다. 코너에 들어간 뒤에야 브레이크를 알려 주는 방식이 아니다.
- 제동 거리는 현재 속도, 코너 목표 속도, 노면 그립, 제동 감속도, 반응 여유로 계산한다. 속도가 낮으면 먼 코너의 안내를 미리 띄우지 않는다.
- 가이드는 조언만 제공한다. 차량 입력, 힘, 속도를 조작하지 않는다. G로 기존처럼 켜고 끌 수 있다.
- 새 CornerSpeedProfile은 코너 그립과 제동 한계를 유지하되, 직선/코너 탈출 가속도를 일정 값으로 제한하던 표시용 속도 곡선을 분리했다. 기존 AI용 DrivingSpeedProfile은 유지한다.
- Harbor Run 예선의 첫 고속 코너에서만 체크포인트 55–95의 기본 횡가속 보정값을 14에서 12로 조정했다. 실제 시험에서 최대 차체 슬립각이 7.09°에서 4.53°로 줄었다. 일반 레이스와 다른 코너에는 이 보정을 적용하지 않는다.
- 앞선 작업의 차량 사운드·슬립스트림·카메라 개선은 세 씬의 20대 모두 유지된다.

## 검증 방법

- 실제 WheelCollider 차량으로 세 서킷의 일반 경로와 예선 경로를 각각 한 바퀴 주행했다. 교통 간섭 없이 코너를 검증하기 위해 상대 차량만 비활성화했다.
- 출발 위치 설정 후에는 스로틀·브레이크·조향으로만 주행했다. 이동 중 속도나 위치를 강제 지정하지 않았고 자동 복구도 끄고 시험했다.
- 직선 풀스로틀, 조건에 맞는 ERS/DRS 사용, 코너 균형 스로틀 및 실제 슬립에 반응하는 시험 운전자 조작을 사용했다. 물리 스텝 0.02초를 유지한 채 시험 시간만 3배로 진행했다.
- 코너별 권장 최저 목표, 실제 통과 속도, 차체 슬립각, 경로 오차, 횡가속을 기록했다. 조밀한 곡률 구간은 하나의 코너 그룹으로 묶으므로 실제 서킷의 공식 코너 번호와 같지 않다.
- 과속 진입에서의 실패를 감추지 않도록 최초 전 구간 결과는 CornerGuide_Initial_PhysicalLaps.json/csv에 보존했다. 실패한 Harbor 예선만 보정 후 재검증했다.
- Yas Marina의 급커브에서 이전 체크포인트의 접선을 무한히 연장해 도로 오차를 측정하던 시험 계산을 수정했다. 인접한 실제 경로 선분과 각 바퀴가 접촉한 TrackSurface로 확인한다. 커브(연석)는 허용하며 네 바퀴 모두 런오프에 닿는 경우는 통과로 인정하지 않는다.
- CornerGuideChecks: 11,468개 검사 통과. 세 씬의 20대 구성, 두 경로의 표시/숨김 구간, 목표 속도 연속성, 직선 숨김, 고속 접근 제동 안내, 저속 접근 및 낮은 그립을 확인했다.

## 결과 파일

최종 결과: 6/6 완주 및 통과, 충돌 0회, 새 콘솔 오류 0개. 총 82개 곡률 구간에서 목표/실측 속도 기록을 얻었다. Yas Marina 예선은 실제 접촉 기준으로 런오프 진입 0초이며, 올바른 인접 경로 선분 기준 최대 도로 중심 편차는 6.15m였다.

| 서킷 | 일반 경로 랩 | 예선 경로 랩 | 일반/예선 최고속도 | 일반/예선 최대 슬립각 |
|---|---:|---:|---:|---:|
| Apex Park | 101.68초 | 103.46초 | 311.85 / 312.00 km/h | 3.16° / 3.67° |
| Harbor Run | 116.26초 | 109.08초 | 283.74 / 287.96 km/h | 2.63° / 4.53° |
| Yas Marina | 139.56초 | 142.04초 | 327.43 / 319.75 km/h | 2.35° / 2.59° |

위 랩은 정지 출발로 한 바퀴를 도는 시험 결과이며, 게임의 예선 최고 기록이나 실제 F1 랩타임이 아니다. 최초 통과한 네 조합은 재사용하고, 보정한 Harbor 예선과 판정 방법을 수정한 Yas Marina 예선만 재검증했다. 최종 파일의 source 필드로 각 결과의 원본을 추적할 수 있다.

- CornerGuide_FinalValidation.json: 최초 합격 결과와 보정 후 재검증 결과를 출처별로 모은 최종 판정.
- CornerGuide_CornerSpeeds.csv: 코너별 목표/실측 속도 표.
- CornerGuide_Initial_PhysicalLaps.json/csv: 최초 6회 주행 및 실패 기록.
- CornerGuide_HarborCalibrated.json/csv: Harbor 예선 보정 후 주행.
- CornerGuide_YasContactValidation.json/csv: Yas Marina 예선 접촉 판정 재검증.
- CornerGuide_Checks.txt: 정적/수치 검사 결과.
- CornerGuide_*_Straight.png 및 *_Corner.png: 실제 가이드 표시 확인 화면.

이 검증은 현재 게임의 차량·노면과 시험 주행 라인에 대한 결과다. 모든 운전 입력에서 가능한 절대 한계 속도나 실제 F1 차량의 성능을 보증하는 수치는 아니다. 코너 진입 자세와 스로틀 균형에 따라 한계가 달라진다.
